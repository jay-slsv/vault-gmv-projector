How accurate is this

Backtest: the model was restarted every week from Jun 21 to Aug 30, using only data available on that date and the spend that actually happened. Miss is projected minus actual GMV over the horizon.

Repeat-spend factor by week (actual ÷ curve)

The factor held between 0.84 and 1.14 from June to August, then fell to 0.74 in the week Meta shut off. It is the biggest single swing input: if it recovers toward 1.0, projected GMV rises by roughly a fifth.

What the model assumes

  • Returns hold at today's levels. Each extra dollar buys the same signup-day GMV as the latest week, with no saturation. Real channels get more expensive as they scale, so large increases are optimistic. TikTok spend per signup already doubled from $7 to $16 as spend grew 7.5x.
  • Apple Search Ads is demand-capped. It already underspends its budget, so adding budget there buys bids, not volume.
  • Channel returns use DB first-touch attribution, which misses some paid signups. Those users sit in organic, so organic lift partly stands in for unrecorded paid users.
  • Meta and Liftoff are $0 by default. Meta is restricted; its multiple is the last clean read (Aug 30-Sep 1). Liftoff has no spend data, so its multiple is a placeholder.
  • GMV is not profit. About 80% of GMV is wallet recycling. The gross profit line uses your margin input (12% ≈ realized margin after shipped cards) and only counts GMV inside the window, so it understates the long-run value of spend near the end of the window.
  • Existing users are aged forward on the same cohort curves, scaled by the repeat-spend factor. Users who signed up before Mar 1 add a flat ~$250/day.
